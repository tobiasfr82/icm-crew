# The ICM Entry Point
The first file that the ICM method relies on is an entry point file called either CLAUDE.md or AGENT.md. The purpose of the file is to tell the AI/LLM what your project is about, where it can find things in your project and instructions that you want AI/LLM to load into it's context window and understand every time it interacts with your project.
