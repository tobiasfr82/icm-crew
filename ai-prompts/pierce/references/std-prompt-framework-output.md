# Output format stage - Part of the Prompt Structure Framework
Specifying the output format is important because it tells the AI what the result should look like. Should the output be a

- list
- table
- Three options to choose from
- Code block with comments?
- Draft with placeholder sections?

## Guiding principle
Output format is the difference between getting something you can use straight away or getting something that you need to spend time on changing the format off.

## Good example 
- Give me three headline options, each under 10 words, followed by a one-sentence explanation of the angle.
- Return this as a markdown table with columns for Task, Owner, Deadline, and Status.
- Write the first draft with [PLACEHOLDER] wherever I need to fill in company-specific details.
- Give me the answer as a numbered list, then add a one-paragraph summary at the end.
