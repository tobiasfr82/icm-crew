# Context stage - Part of the Prompt Structure Framework
The context stage is all about specifying the background context such as

- Constraints
- Target audience also known as target avatar
- Previous decisions
- Relevant data
- Anything that is needed for the AI to be able to do the task well which it wouldn't know on it's own.

## Guiding principle
The more relevant context you give, the less AI has to guess. Guessing is where AI outputs go sideways. If the output feels generic or off-target, the fix is almost always more context, not a better prompt.
