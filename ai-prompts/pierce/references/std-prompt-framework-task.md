# Task stage - Part of the Prompt Structure Framework
The task stage is all about specifying what needs to get done. Being specific is better then general or vague.

## Task specification guideline
- If you read your task specification out loud and a stranger does not understand it and cannot work on it without asking follow up questions the task specification is too vague.

## Good task specification have these three things specified
- A clear action ex. write, review, analyze, compare, build, fix, summarize
- A defined scope ex. how long, how many, what format, what section
- Enough detail ex. so that someone unfamiliar with the project can attempt it. 


## Bad example
- Help me write something

## Good example 
- Write a 200 word product description for [X] targeting [Y] audience
